# Personal Expense Analyzer

A convenient tool for tracking personal finances and analyzing expenses built with Java.

## About the Project
The application helps structure your spending, monitor your budget, and quickly analyze financial habits. The architecture is built on separated service layers, and data is stored locally.

## Key Features
* **Expense Management:** Add, view, edit, and delete financial records seamlessly.
* **Interface Customization:** Modern and adaptive table design featuring unique visual header elements.
* **Reliable Storage:** Automatic saving of all data to a local file for quick access without heavy databases.

## Technologies
* Java
* Swing / FlatLaf (for a modern graphical user interface)
* JSON (for data persistence)
